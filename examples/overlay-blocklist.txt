# muten overlay blocklist — 2026 threat-informed defaults
#
# Compiled 2026-05 from public threat intel: FTC consumer advice,
# Trend Micro, Malwarebytes, Splunk, The Hacker News, Proofpoint TA571,
# Sekoia, Huntress (KongTuke/CrashFix), Gen Threat Labs.
#
# Format:
#   host: <domain>     block any URL on this host or a subdomain of it
#   title: <substring> contribute W_TITLE_HIT to the suspicion score
#   glob: <pattern>    full-string wildcard match (* = any chars, ? = one char)
#   <bare line>        treated as a host rule
#   # comment
#
# SCOPE NOTE: muten's classifier blocks on a CONFIRMED host match or a
# high heuristic score. Title patterns only CONTRIBUTE to the score —
# they never auto-block alone, because legitimate windows can contain
# scary words. This list is meant to be small, auditable, and pushed
# via MDM. It is NOT a replacement for a network-level ad/DNS filter.

# ─────────────────────────────────────────────────────────────────
# COMPOSITE AND-CONDITION RULES  (composite:)
#
# Grammar:  composite: <name> <weight> <cond1> [<cond2> …]
#
# All conditions must hold simultaneously (AND logic). When all fire:
#   • <weight> is added to the suspicion score
#   • <name> is appended to the verdict's signals list and explain()
#
# Available conditions:
#   fullscreen       window covers ≥85% of the display
#   topmost          window is always-on-top
#   no_close_button  window has no usable close affordance
#   blocks_input     window grabs all keyboard/pointer input (modal)
#   unsolicited      window appeared with no user action
#   user_initiated   window appeared after a user click/keypress
#   very_new         window appeared 0 < age_ms < 1000 ms ago
#   alert_shaped     fullscreen OR modal OR no_close_button
#   has_blocklist_title       blocklist_title signal already fired
#   has_phone_number          phone_number signal already fired
#   has_blocklist_phone       blocklist_phone signal already fired
#   has_credential_harvest_cue  credential_harvest_cue signal (E14)
#   has_fake_scanner_cue      fake_scanner_cue signal (E15)
#   has_subscription_lure     subscription_lure signal (E16)
#   has_authority_lure        authority_lure signal (E17)
#   has_screen_share_lure     screen_share_lure signal (E18)
#   has_crypto_drain_lure     crypto_drain_lure signal (E19)
#   has_prize_lure            prize_lure signal (E20)
#   has_download_trap_lure    download_trap_lure signal (E21)
#   has_qr_code_lure          qr_code_lure signal (E22)
#   has_ip_alarm_lure         ip_alarm_lure signal (E23)
#
# BOUNDED-WEIGHT CONVENTION (FP-aversion):
#   A composite covering only geometry/origin (no content tell) should
#   keep the combined score below BLOCK_THRESHOLD (100). The built-in
#   composites use weight 5 for exactly this reason. Add content-tell
#   conditions (has_blocklist_title, has_phone_number) to justify higher
#   weights. See docs/SPECIFICATION.md §6 for the threshold table.
#
